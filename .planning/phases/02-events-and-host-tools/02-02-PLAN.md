# Phase 02 Plan 02: Wire Create Event and Host Dashboard to tRPC Backend

## Objective

Connect the existing Create Event page and Host Dashboard page to the tRPC host router backend. Replace stub handlers and mock data with real API calls. The create event form should call `host.createEvent` with validated input and redirect to the host dashboard on success. The host dashboard should show real events from `host.myEvents` and provide publish/cancel actions.

## Context

Plan 02-01 established:
- Host router with 9 mutations (createEvent, updateEvent, publishEvent, cancelEvent, repeatEvent, createAnnouncement, addCoHost, removeCoHost, setupStripeConnect) and 5 queries (myEvents, eventDetail, eventAttendees, eventAnalytics, searchUsers) in `src/server/routers/host.ts`
- Event router extensions (trackView, getById with images/coHosts/announcements) in `src/server/routers/event.ts`
- hostProcedure middleware for ownership verification in `src/server/trpc/init.ts`
- Zod validators for all inputs in `src/lib/validators/event.ts` and `src/lib/validators/host.ts`
- UploadThing file router in `src/app/api/uploadthing/core.ts`
- tRPC React client with `trpcReact` hooks in `src/lib/trpc.tsx`

The create event page (`src/app/host/create/page.tsx`) currently has only local state and a stub `handleSubmit` that shows a toast. The host profile page (`src/app/host/[id]/page.tsx`) uses mock data from `src/lib/mock-data.ts`.

## Tasks

### Task 1: Wire create event page to host.createEvent tRPC mutation
type="auto"

**What:**
- Replace the stub `handleSubmit` in `src/app/host/create/page.tsx` with a call to `trpcReact.host.createEvent.useMutation()`.
- Construct the mutation input from form state: title, description, category, startsAt (from date+time inputs), endsAt (optional), locationName (from location input), capacity (parsed to number), pricingType (default "free").
- Add validation: require title, category, date, time before submission. Show inline error messages.
- Add loading state during mutation. Disable the submit button while loading.
- On success, redirect to `/host/dashboard` (or show success with eventId).
- On error, display the error message to the user.
- Import and use `trpcReact` from `src/lib/trpc.tsx`.

**Done when:**
- Create event form calls `host.createEvent` mutation with validated input.
- Loading indicator shown during submission.
- Errors are displayed to the user.
- Successful creation redirects or shows success with event ID.
- No TypeScript errors in the modified file.

### Task 2: Build host dashboard page with real data from host.myEvents
type="auto"

**What:**
- Create `src/app/host/dashboard/page.tsx` -- a host dashboard that shows the authenticated user's events.
- Use `trpcReact.host.myEvents.useQuery()` to fetch upcoming and past events.
- Display events in two sections: "Upcoming Events" and "Past Events".
- Each event card shows: title, date/time, status badge (draft/published/cancelled), RSVP count, and action buttons.
- Add action buttons: "Publish" (for drafts, calls `host.publishEvent`), "Cancel" (calls `host.cancelEvent`), "Edit" (links to create page with eventId).
- Add a "Create Event" link/button that navigates to `/host/create`.
- Add a layout file for the dashboard with proper metadata.
- Use the same design system variables as the rest of the app (CSS variables, glass, card-shadow patterns).

**Done when:**
- `/host/dashboard` page loads and shows user's events from the database.
- Events are split into upcoming and past sections.
- Status badges show correctly for draft/published/cancelled events.
- Publish and Cancel action buttons work via tRPC mutations.
- "Create Event" button links to `/host/create`.
- Design matches the existing app style.

### Task 3: Add auth guard and navigation links for host flow
type="auto"

**What:**
- Ensure the host dashboard page redirects unauthenticated users to `/login`.
- Add `authClient.useSession()` checks on the create event page and host dashboard.
- Update the create event layout metadata to say "Create Event" instead of "Create a Host Profile".
- Add a link from the homepage or bottom nav to the host dashboard for authenticated hosts.

**Done when:**
- Unauthenticated users are redirected to `/login` from host pages.
- Session-aware rendering (show user info, show loading state while session resolves).
- Layout metadata is correct.

## Success Criteria

- Create event form submits real data to the backend via tRPC.
- Host dashboard shows real events with status and action buttons.
- Publish/cancel mutations work from the dashboard.
- Auth guards protect host pages.
- No TypeScript errors in modified/created files.
